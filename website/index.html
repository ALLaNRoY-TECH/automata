1.The cast

A machine has five parts. We are six people.

An automaton is written M = (Q, Σ, δ, q₀, F). Five of us are those five parts. The sixth is ε, the move that reads nothing, and one more reason an NFA can be in several places at once.

    3.The trick

    NFADFA

    many possible pasts, folded into one certain present

    An NFA may follow several transitions at once. A DFA follows exactly one. Subset construction removes the difference: each state of the new DFA is a set of NFA states, the set of everywhere the NFA could be right now.

    Start from the ε-closure of q₀. For each set you reach and each symbol, collect where its states can go, close that under ε, and you have the next DFA state. Stop when no new sets appear. A set accepts when it contains an accepting NFA state.

    The construction q′₀ = ε-closure({q₀})
    δ′(S, a) = ε-closure( ∪q ∈ S δ(q, a) )
    F′ = { S : S ∩ F ≠ ∅ }

    step 1 of 4

    Let's build your automaton.

    Enter your NFA, draw its states and transitions, or load an example.

    One transition per line, like q0, 1 -> q0, q1. Write eps for ε. Leave out moves that don't exist.

    Full format 
    States: q0, q1, q2
Alphabet: 0, 1
Start: q0
Accepting: q2
Transitions:
q0, 0 -> q0, q1
q1, eps -> q2
    • Every symbol used in a transition must be listed in Alphabet. The lab never adds symbols for you.
    • Several targets after -> make it nondeterministic. Leave a move out, or write ∅, for “no move”.
    • Symbols are single characters (letters or digits). State names use letters, digits, _ or ', up to 12 characters.
    • none, empty and eps are reserved words, not state names.
    • Lines starting with # are comments.

    Pick one. It loads into the editor, where you can change anything.
